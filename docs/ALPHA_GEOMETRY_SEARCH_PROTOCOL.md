# Alpha-geometry search protocol

Status: `STAGE_0_PILOT_COMPLETE` after explicit human authorization on 14
November 2026.

This is a new, separate search programme. It does not modify the known-physics
baseline campaign and it does not claim that a graph invariant is a derivation
of the fine-structure constant.

## Scientific boundary

The pilot starts from simple finite connected graphs and a deliberately small
action grammar. It computes only structural invariants. The value of
`alpha`, its running with energy, and the vacuum electromagnetic normalization
are not read or fitted in stage 0.

The target is therefore not to find a number by construction. The target is to
test whether the laboratory can enumerate a declared mathematical family,
identify equivalent descriptions, preserve provenance, and stop before an
arbitrary map from geometry to `alpha` is silently inserted.

## Stage 0 grammar

The executed pilot contains:

- graph families: cycle, path, complete;
- sizes: `n=3,...,7`;
- action families: quadratic graph-Laplacian and local quartic extension;
- 30 raw records before canonical deduplication;
- 28 unique records after identifying `C3 ~= K3`;
- no external data, fit, selection, ranking, or empirical comparison.

The derived quantities are finite graph invariants: edge density, degree
sequence, Laplacian gap and radius, normalized gap, and spanning-tree count.
They are diagnostic outputs, not electromagnetic observables.

## Required next gate

Before any comparison with `alpha^{-1} ~= 137`, a surviving geometry must
receive an explicit U(1) formulation:

1. field content and gauge symmetry;
2. action and normalization;
3. quantization or classical limit, explicitly stated;
4. definition of charge and coupling;
5. derivation of the observable used for `alpha`;
6. a declared scale, because the electromagnetic coupling runs;
7. an independent prediction not used to construct the candidate.

If a continuous parameter is chosen to make a derived invariant equal to
`1/137`, the result is labelled calibrated and is not a prediction.

## Unconfirmed frameworks

String theory, loop quantum gravity, causal dynamical triangulations,
asymptotic safety, noncommutative geometry and emergent-gravity families are
registered separately as possible sources of explicit candidates. A family
name is not executable: each entry must provide one action, one state/vacuum
prescription, one observable map and finite bounds before it enters a pilot.

## Stopping rules

Stop a branch when it violates a hard consistency condition, duplicates an
existing canonical record, adds only a reparameterization, or requires an
unbounded search window. Stop the entire stage when new grammar elements no
longer produce new equivalence classes or independent observables. A surviving
candidate is not selected automatically; human review remains mandatory.

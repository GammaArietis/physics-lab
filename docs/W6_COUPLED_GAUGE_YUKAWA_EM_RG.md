# W6 — Coupled gauge–Yukawa and electromagnetic RG campaign

W6 tests the first mechanism capable of producing an interacting fixed point
without inserting a target value for the electromagnetic coupling. The
gauge–Yukawa sector uses the NLO equations of Litim and Sannino:

\[
\begin{aligned}
\beta_g &= \alpha_g^2\left[
\frac{4}{3}\epsilon
 +\left(25+\frac{26}{3}\epsilon\right)\alpha_g
 -2\left(\frac{11}{2}+\epsilon\right)^2\alpha_y
\right],\\
\beta_y &= \alpha_y\left[(13+2\epsilon)\alpha_y-6\alpha_g\right].
\end{aligned}
\]

The Abelian coupling is included as a one-loop QED spectator:

\[
\beta_{\rm em}=\frac{2}{3\pi}\alpha_{\rm em}^2.
\]

## Campaign

- 8 values of the Veneziano control parameter \(\epsilon\);
- 3 non-zero electromagnetic seeds per value;
- 24 coupled trajectories;
- fixed-point residuals and stability matrices recorded;
- no experimental data, no alpha fitting, no ranking or selection.

## Result

For every scanned positive \(\epsilon\), the code finds a physical
non-Gaussian fixed point in the gauge–Yukawa subsector:

\[
(\alpha_{\rm em}^*,\alpha_g^*,\alpha_y^*)
=(0,\alpha_g^*,\alpha_y^*),
\qquad \alpha_g^*>0,\;\alpha_y^*>0.
\]

The electromagnetic coordinate remains exactly Gaussian. This is the central
result of W6: an interacting fixed point can be generated by opposite-sign
gauge/Yukawa contributions, but this mechanism does not by itself determine a
non-zero electromagnetic coupling and therefore does not derive \(1/137\).

The larger \(\epsilon\) values are retained as stress diagnostics; they are
not automatically regarded as perturbatively reliable. The original paper
itself emphasises the small-\(\epsilon\) control regime and the need to inspect
stability, scalar couplings and higher-order corrections.
